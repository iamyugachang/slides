23迷思PART 3 · 分層架構

五個常見迷思

「A2A 是 MCP 的下一代」

錯。不同層：MCP 連工具與資料，A2A 連 agent 與 agent。

各自解決不同的連接問題

「Skills 是咒語，加了就變強」

錯。沒有說明、範例、測試與正確載入時機，skill 只是文件。

包裝 ≠ 能力保證

「Loop 是 2026 的新功能」

錯。Loop 是 agent 的基本型態；進步在於可觀測、可評估、可恢復。

進步在讓 loop 可信

「上下文越長越好」
