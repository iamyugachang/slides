# Habit Quest — 教學產品 brief

這是可以修改的教學假設，請先討論再初始化，尚未授權直接實作。

## 使用者與問題
想維持閱讀或運動的個人使用者，常因回饋不明顯而中斷。
希望真實行動帶來角色成長，增加明天回來的動機。此效果仍需驗證。

## 核心循環
新增每日習慣 → 今日任務 → 完成 → +20 XP → 角色升級 → 固定裝備與原創劇情解鎖。

## 第一個可驗收切片
手機可用的響應式 web app。新增習慣、今日打卡、XP/等級、localStorage 保存。
先單人、單裝置，不做帳號、雲端同步、多人、商店、AI 劇情或戰鬥。

## 後續小型 MVP
Lv.2 解鎖晨光徽章。故事第一節在開始時可讀，Lv.3 解鎖第二節。
再補上匯出/還原、可及性、回歸測試與部署。

## 規則草稿
- 每個 habitId 在 Asia/Taipei 的同一日期只能領取一次 20 XP。
- Level = 1 + floor(totalXP / 100)；本級 XP = totalXP % 100。
- Total XP 不因升級歸零；漏做一天不扣 XP。
- 00:00 換日，重新開啟或取得焦點時更新今日任務；保留歷史。
- 第一版沒有補打卡、撤銷或可變時區。
- 儲存失敗必須提示，不能顯示已永久成功。
- localStorage 清除會遺失，不支援跨裝置、防作弊或多分頁並行一致性。

## 成功訊號
工程：不重複領 XP、100 XP 邊界正確、跨日正確、重整仍保留。
產品：少量試用者連用一週，能理解下一步，願意回來，認為獎勵有意義。
